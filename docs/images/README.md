# HARP documentation images

Place current UI screenshots for the repository README and ICICLE Training Catalog in this directory.

The required filenames, screen states, redaction rules, and maintenance checklist are in [`../README_CONTENT_PLAN.md`](../README_CONTENT_PLAN.md). The root [`README.md`](../../README.md) contains visible screenshot slots showing exactly where each image belongs.

Do not copy the legacy screenshots from `DEMO/images/` into this directory. Capture the current UI with example data. Never include tokens or passwords; include an allocation only when the documentation owner explicitly approves it. Keep the first capture of every screen unannotated, then save the red-box copy with an `-annotated.png` suffix.
